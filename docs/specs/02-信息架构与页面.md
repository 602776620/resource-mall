# 02 · 信息架构与页面

> 前端单项目：`web/`（Vite + React + TS）。路由分两区：`/` 前台、`/admin` 后台（管理员守卫）。

## 1. 路由总表

### 前台

| 路由 | 页面 | 登录要求 | 说明 |
|---|---|---|---|
| `/` | 首页 | 否 | 轮播/精选（取 is_listed 按 created_at 倒序前 12）+ 分类入口 + 最新上架 |
| `/products` | 资源列表 | 否 | query：`category` `keyword` `sort`(new/price_asc/price_desc) `price_min` `price_max` `page`；左侧筛选栏 + 顶部排序 + 底部分页（20/页） |
| `/products/:id` | 商品详情 | 否 | 封面、简介富文本、预览媒体区（图可放大/样本文件可公开下载）、价格（原价划线）、标签、「立即购买」（未登录→跳登录回跳） |
| `/orders/create/:id` | 下单确认 | 是 | 商品摘要 + 券码输入框（输入即调校验接口显示抵扣）+ 应付金额 + 「提交订单」 |
| `/orders/:orderNo/payment` | **待支付页** | 是（本人） | 收款码大图（按所选渠道）+ 金额 + 订单号（可复制）+ 30 分钟倒计时 + 状态轮询（5s）+「我已付款」按钮→弹层填支付说明（必填≥5字）；页尾「取消订单」 |
| `/orders` | 我的订单 | 是 | 状态 Tab：全部/待支付/待核销(pending且已提交)/已完成(paid)/已取消/已撤销；列：商品、订单号、金额、状态、时间、操作（去支付/去下载/复制订单号） |
| `/downloads` | 下载中心 | 是 | 已支付(paid)订单列表：商品、购买时间、剩余下载次数（7 天 50 次内）、倒计时、「下载」按钮（调接口 302 触发） |
| `/login` | 登录 | — | 账号(用户名或邮箱)+密码；登录成功按 `redirect` 回跳 |
| `/register` | 注册 | — | 用户名+邮箱+密码+确认 |
| `/404` `/403` | 错误页 | — | 403 页带「登录」按钮 |

### 后台（/admin，守卫：未登录跳 /login?redirect=/admin，非管理员 403 页）

| 路由 | 页面 | 说明 |
|---|---|---|
| `/admin` | 概览 | 卡片：今日订单数、待核销数（pending 且 paid_submitted）、在售商品数、本周 GMV(已核销金额)；快捷入口 |
| `/admin/products` | 资源列表 | 表格：封面缩略、标题、分类、价格、上下架状态、创建时间；操作：编辑/上下架/删除（有订单的商品禁删，仅可下架） |
| `/admin/products/new` · `/admin/products/:id/edit` | 资源表单 | 标题/副标题/分类/标签(逗号分隔)/价格/原价/封面上传/描述富文本(简化：textarea 多行，MVP 不做富文本编辑器，渲染端用白名单过滤)/预览图多图(≤9)/预览样本文件(≤3, 单个≤20MB)/资源文件(≤2GB)；「保存」与「保存并上架」 |
| `/admin/orders` | 订单列表 | Tab：待支付/待核销/已支付/已取消/已撤销/全部；搜索：订单号精确 or 用户名模糊；行操作：查看详情抽屉 |
| `/admin/orders/reconcile` | **核销工作台** | 待核销队列（paid_submitted 非空的 pending，按提交时间正序）；每行高亮三方：订单号 / 应付金额 / 用户支付说明；渠道单选(微信/支付宝)+「核销」；二次确认弹层要求输入订单号后 6 位；支持批量核销（勾选+统一渠道，逐单条件更新） |
| `/admin/orders/:id` | 订单详情 | 全字段 + 操作（核销/撤销/撤销需填理由≥5字）+ 下载日志（次数/时间/IP） |
| `/admin/coupons` | 券码管理 | 生成表单（类型 fixed/percent、值、上限、有效期、数量≤100）；列表（code 可复制、已用/上限、状态、停用按钮）；行展开看使用明细（订单号/用户/时间） |
| `/admin/users` | 用户列表 | 只读表格（用户名/邮箱/注册时间/订单数/是否管理员）+ 禁用/启用（禁用后登录 403）；MVP 不支持后台改密 |
| `/admin/audit` | 审计日志 | 表格：时间/操作人/动作/对象/理由/IP；筛选：动作类型+时间范围 |

## 2. 关键流程跳转（前台主链）

```
首页/列表 ──▶ 详情 ──▶ 下单确认(登录) ──▶ 提交订单 ──▶ 待支付页
                                                      │  我已付款+说明
                                          后台核销 ◀──┘
                                                      │
详情/下载中心 ◀── 支付完成(轮询到 paid) ◀──────────────┘
```

后台核销动作与用户侧无实时推送，用户通过**待支付页 5s 轮询**与**我的订单页手动刷新**感知。

## 3. 页面状态约定（所有列表/详情页统一）

| 状态 | 表现 |
|---|---|
| loading | 骨架屏（列表）/ 居中 spinner（表单提交） |
| empty | 空态插画 + 文案 + 主行动按钮 |
| error | 错误卡片 + 「重试」按钮；401 走全局刷新→失败跳登录；403 跳 403 页 |
| partial | 分页/筛选变更保留 query 于 URL（可分享/回退） |

## 4. 组件与交互红线

1. 金额展示统一 `¥` + 两位小数（前端分→元转换，禁止直接展示分）。
2. 订单号/券码展示用等宽字体 + 「复制」按钮。
3. 所有文件上传：进度条 + 失败重试 + 服务端大小校验兜底（前端限制见 04 错误码表）。
4. 待支付页倒计时归零 → 自动调取消 + 提示刷新状态。
5. 富文本渲染：MVP 描述列仅支持 `<p><br><b><ul><li><a><img><pre><code><h1-h3>` 白名单，其余标签服务端入库前剥离（06 号安全）。
