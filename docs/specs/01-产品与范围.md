# 01 · 产品与范围

## 1. 产品定位

自营单店虚拟资源商城：运营方（管理员）上传虚拟资源（教程、模板、资料、AI 素材），用户注册后浏览/搜索/购买，通过**微信/支付宝个人收款码扫码付款**，管理员**人工核销**后用户获得限时下载权限。

一句话：**卖虚拟文件，收钱靠扫码，发货靠核销。**

## 2. 用户角色

| 角色 | 说明 |
|---|---|
| 游客 | 未登录，可浏览已上架商品与预览 |
| 注册用户 | 登录后可下单、查看订单、下载已支付资源 |
| 管理员（is_admin） | 登录后额外可访问 /admin：资源管理、核销、券码、用户、审计 |

## 3. 核心用户故事

### 买家线
- **US-B1 浏览**：作为游客，我想按分类/关键词/价格筛选并搜索资源，看到封面、简介、预览图/样本，以便判断是否购买。
- **US-B2 购买**：作为注册用户，我想在商品页输入券码下单，看到应付金额、收款码、订单号，以便扫码支付。
- **US-B3 通知**：作为注册用户，我付完款后点「我已付款」并填支付说明，以便管理员核对核销。
- **US-B4 下载**：作为注册用户，核销后我想在下载中心反复下载（7 天内 50 次），链接 15 分钟内有效。
- **US-B5 取消**：作为注册用户，未支付时我想主动取消订单。

### 管理员线
- **US-A1 资源管理**：作为管理员，我想上传资源（封面/预览/资源文件）并上架，以便对外售卖。
- **US-A2 核销**：作为管理员，我想在核销工作台按订单号检索待核销订单，比对**订单号+金额+支付说明**三方一致后核销。
- **US-A3 撤销**：作为管理员，我想撤销已核销订单（必填理由），使其下载权限立即失效。
- **US-A4 券码**：作为管理员，我想批量生成/停用券码并查看使用明细。
- **US-A5 审计**：作为管理员，我想查看核销/撤销/资源上下架等关键操作的审计日志。

### 系统线
- **US-S1 超时取消**：系统对 30 分钟未支付的 pending 订单自动置 cancelled。
- **US-S2 限流**：系统限制同一订单 7 天内 50 次下载、下单/登录接口 IP 级限流。

## 4. MVP 功能清单（本版本必做）

| 模块 | 功能 | 对应规范 |
|---|---|---|
| 认证 | 注册（用户名/邮箱+密码）、登录、refresh 轮换、改密、管理员 seed | 04/05 |
| 商品 | CRUD+上传、上下架、分类、标签 | 03/04 |
| 浏览 | 首页/列表分页/分类筛选/价格筛选/关键词搜索/详情/预览媒体访问 | 04/05 |
| 订单 | 创建（服务端算价+券码校验）、我的订单、取消、30min 超时取消 | 03/05 |
| 支付 | 待支付页（静态收款码+金额+订单号）、「我已付款」+支付说明 | 05 |
| 核销 | 核销工作台（订单号精确检索+三方比对+禁止模糊核销）、撤销 | 05/06 |
| 下载 | 下载中心、签名短链（15min/绑定订单/消费前复核）、7 天 50 次限流 | 03/05/06 |
| 券码 | 批量生成、金额/折扣两种、用量上限、有效期、停用、使用明细 | 03/05 |
| 后台 | /admin 守卫、资源/订单(核销)/券码/用户/审计 五区 | 02 |
| 安全 | 越权防护、downloads/ 禁直连、密钥管理、审计日志 | 06 |

## 5. 非目标清单（MVP 明确不做，防止范围蔓延）

1. ❌ 多商家/创作者入驻、分账、提现
2. ❌ 支付自动回调/自动对账（个人收款码不支持，MVP 为纯人工核销）
3. ❌ 评论、评分、收藏、分享裂变
4. ❌ 售后/自动退款（仅人工撤销，见 US-A3）
5. ❌ 数据统计看板（订单量/收入报表）
6. ❌ 邮箱/短信找回密码（MVP 无找回通道，忘记密码联系管理员改密）
7. ❌ 微信/支付宝 OAuth 登录
8. ❌ 多语言、移动端 App、PWA
9. ❌ OSS/CDN 对象存储（MVP 用本地磁盘 + 签名短链）
10. ❌ 向量语义搜索（仅预留表结构，见 03/10）
11. ❌ 订单拆单/购物车批量结算（一单一商品）

## 6. 成功标准（MVP 完成定义）

1. 09 号文档验收项 **100% 勾选**，含 5 条端到端路径（环境/买家/管理员/安全/并发）。
2. 一个陌生人按 08 号文档 **30 分钟内**从零起好本地环境并跑通 E2E。
3. 核心竞态（重复核销、券超发）在并发测试下 **0 事故**。
4. `downloads/` 内任一文件 **无法**通过猜测 URL 直接访问。

## 7. 边界依赖

- 支付码图片（`wechat.png`/`alipay.png`）由运营方提供，放入 `uploads/payment/`（该目录内容可公开，仅收款码图片）。
- 域名/备案/ICP：MVP 本地开发不涉及；上线前事项列入 10 号文档。
