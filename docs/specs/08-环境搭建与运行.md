## 3. docker-compose.yml（T01 落盘）

```yaml
services:
  db:
    image: postgres:16
    container_name: mall_db
    environment:
      POSTGRES_DB: mall
      POSTGRES_USER: mall
      POSTGRES_PASSWORD: ${DB_PASSWORD}
    ports: ["127.0.0.1:5432:5432"]     # 仅回环（06）
    volumes: [mall_pgdata:/var/lib/postgresql/data]
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U mall -d mall"]
      interval: 5s
  redis:
    image: redis:7
    container_name: mall_redis
    command: ["redis-server", "--requirepass", "${REDIS_PASSWORD}"]
    ports: ["127.0.0.1:16379:6379"]   # 宿主机 6379 被本机 redis-server 占用（2026-11-10 实测），见 §8.1
    volumes: [mall_redisdata:/data]
volumes:
  mall_pgdata:
  mall_redisdata:
```

## 6. 常用运维命令

| 操作 | 命令 |
|---|---|
| 起/停容器 | `docker compose up -d` / `docker compose down`（加 `-v` 删数据） |
| 进 PG | `docker compose exec db psql -U mall -d mall` |
| 备份 | `./backup.sh`（06 §6，pg_dump -Fc → backups/pg/，保留 14 份） |
| 恢复 | `pg_restore -d mall -c backups/pg/mall-*.dump`（先 down 应用） |
| 清限流缓存 | `docker compose exec redis redis-cli -a $REDIS_PASSWORD FLUSHDB`（慎用，限流清零） |

## 7. 启动自检（/health）

`GET /health` 返回 db/redis 双 OK 方可进入验收（09 环境路径）。任一 fail → 503，日志定位（DSN 错/端口冲突/防火墙）。

## 8. 常见问题（实测预留）

1. 端口 5432/6379 被占 → 改 compose 映射（宿主机侧端口，如 15432/16379），同步 .env。**本机实测（2026-11-10）：6379 被系统 redis-server.exe 占用 → Redis 映射改为 `127.0.0.1:16379:6379`，`.env` 的 `REDIS_DSN` 同步为 `redis://127.0.0.1:16379/0`。**
2. Windows Docker Desktop 未启动 → 先启动再 compose。
2a. **Docker Hub 直连不通（2026-11-10 实测）** → 拉镜像走镜像站前缀：`docker pull docker.m.daocloud.io/library/postgres:16 && docker tag docker.m.daocloud.io/library/postgres:16 postgres:16`（redis:7 同理）。compose 文件仍写标准镜像名，tag 后即命中本地。
3. `pip install` 报 psycopg 编译错 → 用 `psycopg[binary]`（已锁）。
4. 前端 proxy 502 → 后端未起或端口错（vite.config proxy target 8000）。
