# 10 · 后续迭代（非 MVP 路线图）

> 按优先级排序；每项标注「触发条件」= 满足才做，避免过早复杂化。

## P1 高频候选

### 1. 向量语义搜索（pgvector）
- **触发**：商品数 > 500 或出现"搜不到想要的"反馈。
- **步骤**：
  1. compose 镜像 `postgres:16` → `pgvector/pgvector:pg16`（**不迁数据**，仅加扩展）。
  2. `CREATE EXTENSION vector;` + 建 `products_embedding` 表（03 §4）+ HNSW 索引。
  3. 商品保存/编辑时异步生成 embedding（标题+副标题+标签+描述），embedding 模型先用本地或 API（选模型单独立项）。
  4. 搜索接口升级：keyword 未命中或低相关时追加向量召回，按余弦相似度排序混合。
- **AI 素材智能推荐**：基于"用户下载历史 → 商品向量"做相似推荐（详情页"猜你喜欢"）。
- **RAG 问答**（更后）：商品库向量化 + 问答页；需引入 LLM 调用与成本控制。

### 2. 支付自动化
- **触发**：核销积压 > 5 单/日 或 申请到**企业商户号**。
- 路线：支付宝当面付/网站支付（个人身份可开）→ 标准异步回调自动核销，保留人工兜底。
- 个人收款码**封号风险**（经营性收款）：商户号化是长期正解。

### 3. OSS/CDN 文件迁移
- **触发**：磁盘 > 500GB 或 需要公网上线。
- 资源文件迁 OSS/COS + 私有签名 URL；`downloads/` 本地目录废弃；CDN 加速预览图。

## 运营风险备忘（上线前必读）

1. **个人收款码**：经营性收款违反微信/支付宝个人码协议，有**限制/封号**风险；金额大了尽快商户号化（P1-2）。
2. **虚拟资源盗版**：无 DRM，签名短链 15min 内可转发；靠"短时效+不公开目录+用户协议"降低风险，MVP 接受。
3. **备份**：本地磁盘单点，上线前必须落 OSS 或双盘（P1-3 后由 OSS 解决）。
4. **合规**：ICP/公安备案、隐私政策、个人信息保护（06 §8 清单）。
