## 2. 术语表（全项目统一用词，禁止同义词混用）

| 术语 | 定义 | 禁用同义词 |
|---|---|---|
| **资源 / 商品**（product） | 一条可售卖的虚拟资源记录（教程/模板/资料/AI 素材），含封面、预览媒体、资源文件 | 产品、宝贝、文件 |
| **资源文件**（file） | 购买后实际下载的压缩包/文件，存放于 `downloads/`，**仅签名短链可访问** | 附件 |
| **预览媒体**（preview_media） | 未购买即可见的预览图/样本文件，存放于 `uploads/`，可公开访问 | 截图 |
| **订单**（order） | 用户购买一个商品的一次交易记录，订单号 `order_no` 全局唯一 | 交易 |
| **核销**（confirm） | 管理员确认用户已线下扫码付款，将订单 pending → paid 的人工动作 | 打款、确认付款 |
| **撤销**（revoke） | 管理员将 paid 订单回退为无效（paid → revoked），下载权限作废 | 退款 |
| **超时取消**（cancelled） | pending 订单 30 分钟未支付自动/用户主动取消 | 作废 |
| **签名短链**（signed link） | 后端生成的 HMAC 签名临时下载 URL，15 分钟有效、绑定 order_id | 下载链接 |
| **券码**（coupon） | 运营批量生成的折扣码，用户下单时输入抵扣 | 优惠券（口语可用，文档用"券码"） |
| **核销工作台**（reconcile） | 后台"待核销订单"专属操作页，按订单号+金额+支付说明三方比对 | 订单处理页 |
| **上架 / 下架**（listed） | 商品对外可见性的开关（is_listed） | 发布/隐藏 |
| **降级**（degrade） | Redis 等组件不可用时按预设策略降低功能但保持核心可用的行为 | 兜底 |

## 3. 已锁定的产品/技术决策（2026-11-09 与用户确认）

| 维度 | 决策 |
|---|---|
| 技术栈 | 后端 FastAPI + SQLAlchemy 2.x + Alembic + Redis；前端 React + Vite + TypeScript |
| 数据库 | **PostgreSQL 16**（docker compose 容器；为 pgvector 预留）；**Redis 7**（docker compose 容器） |
| 业务模式 | 自营单店（无创作者入驻、无分账提现） |
| 支付 | 微信/支付宝**个人收款码 + 后台人工核销**；用户侧「我已付款」按钮 + 支付说明回传 |
| 文件交付 | 服务器本地磁盘 `downloads/`，HMAC 签名限时短链（15 分钟，绑定 order_id） |
| 登录 | 用户名/邮箱 + 密码（argon2id），JWT access 15min + refresh 7d（refresh_tokens 表轮换） |
| 管理后台 | 同一 React 项目 `/admin` 路由，独立管理员守卫 |
| MVP 范围 | 核心闭环 + 搜索/筛选 + 资源预览 + 券码 |
| 非目标 | 见 01 号文档非目标清单 |
| Git | `resource-mall` 内**独立 git init**（现处于共享仓库 programs 内，禁止向共享库提交） |
| Python | 本机默认 3.8.5（EOL）弃用；**Python 3.13**（`E:\Users\60277\AppData\Local\Programs\Python\Python313\python.exe`）建 venv |
| Node | v24.22.1 |
| Docker | 28.0.4 + Compose 2.34，仅用于拉起 PG/Redis 容器 |
